---
title: "Import data"
description: "Upload transaction files and review the import results."
---

Use **Import transactions** to upload a CSV or XLSX spreadsheet. Prepare the file first and make sure each column has a header.

## Upload and confirm

<Steps>
  <Step title="Upload the file">
    Select a file to preview its rows and suggested column mappings.
  </Step>
  <Step title="Review the columns">
    Check each column mapping. Fix any suggestion that does not match your data.
  </Step>
  <Step title="Confirm the import">
    Review and confirm the mapping. Check import history for status and errors.
  </Step>
</Steps>

Do not upload passwords, tokens or files you are not authorized to handle. If processing reports errors, fix the file and confirm the records were not processed before importing again.
