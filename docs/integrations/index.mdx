As integrações permitem trocar informação entre o Complyz e outros serviços.
Consulte a disponibilidade e os requisitos de cada ligação antes de preparar
um processo de sincronização.

## API Complyz

A API usa `https://api.trycomplyz.com` e expõe operações em `/api/v1`. Consulte a
[referência interactiva](/api) para operações, autenticação e formatos de
resposta.

## Ligações planeadas

As páginas de [Google Drive](/integrations/google-drive) e
[Google Workspace](/integrations/google-workspace) descrevem possibilidades
futuras. Estas ligações ainda não estão disponíveis: não crie credenciais nem
fluxos de produção com base nesses planos.
