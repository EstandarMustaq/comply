# Internal traceability

This document is engineering-only. It maps product capabilities to internal compliance requirements and source obligations. It must not be linked from the UI, returned by the API, used as user-facing error text, or embedded in product exports.

The implementation uses this document to preserve evidence, retention, reporting, screening, and review controls while keeping product language independent from external legal terminology.

When a requirement changes, update the capability, acceptance criteria, migration impact, audit evidence, and release gate here.
